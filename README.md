# Produktifa - Aplikasi Manajemen Proyek & Tugas Tim

Aplikasi manajemen proyek, tugas kanban, gamifikasi produktivitas, dan chat tim real-time berbasis **React 19 + TypeScript + Express + SQLite + WebSockets**.

---

## Cara Menjalankan di Komputer Lokal (Development)

1. **Pastikan Node.js v20+ atau v22+ telah terinstal di komputer Anda.**
2. Buka terminal di dalam folder proyek ini, lalu pasang dependensi:
   ```bash
   npm install
   ```
3. Salin file konfigurasi environment:
   ```bash
   cp .env.example .env
   ```
4. Jalankan aplikasi:
   ```bash
   npm run dev
   ```
5. Buka peramban di [http://localhost:3000](http://localhost:3000).
